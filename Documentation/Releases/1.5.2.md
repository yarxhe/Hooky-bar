# Hooky bar 1.5.2

## Русский

Релиз 1.5.2 делает панель заметно легче в покое и при навигации, сохраняя плавные системные анимации macOS.

### Что нового

- переходы вкладок и геометрии переведены на ограниченные системные SwiftUI/Core Animation анимации;
- страницы панели переиспользуются безопасно, без дублирования hosting views при быстрых переключениях;
- визуализатор больше не перерисовывает всё SwiftUI-дерево и останавливается, когда не виден;
- mini-player мягко подстраивается под занятые области строки меню;
- улучшены отступы буфера и форма кнопки очистки;
- снижена стоимость прокрутки Dev-панели и фоновых обновлений;
- команды Яндекс Музыки, MediaRemote и служебные процессы получили ограниченные таймауты и объём ответов;
- добавлен повторяемый UI/performance-тест раскрытия, вкладок, фильтров, прокрутки, CPU и памяти;
- диагностическое логирование по умолчанию выключено и включается только через `debugLogging`.

Проверенная сборка возвращается к 0–0,2% CPU в покое после циклов интерфейса и не показывает удержания памяти. DMG подписан ad-hoc, но не Apple Developer ID и не нотарифицирован. При первом запуске используйте контекстное меню **Открыть** и подтвердите запуск в настройках безопасности macOS.

## English

Release 1.5.2 makes the panel substantially lighter at idle and during navigation while preserving smooth system-native macOS motion.

### What's new

- tab and geometry transitions now use bounded system SwiftUI/Core Animation motion;
- panel pages are safely reused without duplicate hosting views during rapid switching;
- the visualizer no longer redraws the full SwiftUI tree and stops when it is not visible;
- the mini-player adapts smoothly to occupied menu-bar regions;
- clipboard spacing and the clear-button shape have been refined;
- Dev scrolling and background refresh work are cheaper;
- Yandex Music, MediaRemote, and helper-process calls now have bounded timeouts and output sizes;
- a repeatable UI/performance check covers expansion, tabs, filters, scrolling, CPU, and memory;
- diagnostic logging remains off by default and is enabled only through `debugLogging`.

The verified build returns to 0–0.2% idle CPU after interface cycles and shows no retained memory. The DMG is ad-hoc signed, not Apple Developer ID-signed or notarized. On first launch, use **Open** from the context menu and allow the app in macOS security settings.
