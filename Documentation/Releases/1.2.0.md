# Hooky bar 1.2.0

## Русский

Первый стабильный выпуск Hooky bar — компактной панели для выреза MacBook.

### Что нового

- расширенная Dev-панель со статусом Git, последним GitHub Actions workflow, issues, релизами и обсуждениями pull request;
- команды запуска, тестирования и сборки проекта через единый внутренний адаптер;
- быстрый переход в выбранную IDE, Terminal, Finder и GitHub;
- цельная анимация системных уведомлений для Bluetooth, VPN, Calendar и AirDrop;
- исправлена прокрутка Dev-панели: карточки больше не перекрывают навигацию;
- устранены размытие текста и просадки производительности в Dev-панели;
- улучшена архитектура адаптеров и добавлены контрактные тесты.

Сборка не подписана Apple Developer ID. При первом запуске используйте контекстное меню **Открыть** и подтвердите запуск в настройках безопасности macOS.

## English

The first stable Hooky bar release — a compact utility for the MacBook notch.

### What's new

- an expanded Dev page with Git status, the latest GitHub Actions workflow, issues, releases, and pull request discussions;
- project run, test, and build commands routed through a unified internal adapter;
- quick access to the selected IDE, Terminal, Finder, and GitHub;
- unified system-event animation for Bluetooth, VPN, Calendar, and AirDrop;
- fixed Dev page scrolling so cards no longer overlap navigation;
- removed text blur and performance drops in the Dev page;
- improved adapter architecture with contract tests.

This build is not signed with an Apple Developer ID. On first launch, use **Open** from the context menu and allow the app in macOS security settings.
