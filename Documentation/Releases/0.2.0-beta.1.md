# Hooky bar 0.2.0 Beta 1

## Русский

Первая публичная бета Hooky bar — бесплатной open-source панели для выреза MacBook.

### Главное

- управление Яндекс Музыкой, Apple Music и Spotify;
- mini-player, обложки, следующий трек, перемотка, громкость, like/dislike;
- история текстового буфера и скриншотов с поиском и закреплением;
- фокус-таймер, быстрые заметки и системные утилиты;
- события Bluetooth, VPN, Calendar и AirDrop;
- отдельная Dev-панель для проекта, Git и GitHub Actions;
- русский и английский интерфейс.

В Beta 1 исправлены управление громкостью на устройствах без scalar master-канала, обновление времени после смены трека и совместная анимация названия с обложкой. Внутренние интеграции переведены на типизированные адаптеры и покрыты контрактными тестами.

Сборка не подписана Apple Developer ID. При первом запуске используйте контекстное меню **Открыть** и подтвердите запуск в настройках безопасности macOS.

## English

The first public beta of Hooky bar — a free, open-source utility for the MacBook notch.

### Highlights

- controls for Yandex Music, Apple Music, and Spotify;
- mini-player, artwork, upcoming track, seeking, volume, like/dislike;
- searchable clipboard and screenshot history with pinned items;
- focus timer, quick notes, and system utilities;
- Bluetooth, VPN, Calendar, and AirDrop events;
- a dedicated Dev view for projects, Git, and GitHub Actions;
- Russian and English interface.

Beta 1 fixes volume control on devices without a scalar master channel, stale elapsed time after track changes, and synchronizes artwork with title transitions. Internal integrations now use typed adapter contracts covered by regression tests.

This build is not signed with an Apple Developer ID. On first launch, use **Open** from the context menu and allow the app in macOS security settings.
