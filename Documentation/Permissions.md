# Разрешения и доступы

[Русский](Permissions.md) · [English](Permissions.en.md)

Hooky bar использует системный доступ только при включении или первом использовании соответствующей функции. Некоторые файловые источники начинают мониторинг вместе с приложением. Разрешение не означает постоянную запись экрана или прослушивание аудио.

| Доступ | Для чего нужен | Когда нужен | Обязателен |
|---|---|---|---:|
| Automation / Apple Events | Управление Apple Music, Spotify и создание заметки Apple Notes | При первой команде соответствующему приложению | нет |
| Accessibility | Резервное управление нативной Яндекс Музыкой, если CDP недоступен | При использовании функций Яндекс Музыки, которым нужен fallback | нет |
| Bluetooth | События подключения и отключения устройств | После включения Bluetooth-событий | нет |
| Calendar | Ближайшая встреча из Apple Calendar | После включения календаря | нет |
| Desktop Folder | Чтение скриншотов, если папка скриншотов находится на Рабочем столе | При первом запуске мониторинга буфера; сейчас он стартует вместе с Hooky bar | нет |
| Downloads Folder | Событие о новом AirDrop-файле в Загрузках | После включения AirDrop-событий | нет |
| Локальное соединение | Подключение к CDP Яндекс Музыки на `127.0.0.1` | При использовании CDP bridge; отдельного системного prompt обычно нет | нет |

## Что приложение не должно запрашивать

- Screen Recording;
- Microphone;
- Camera;
- Full Disk Access;
- Contacts;
- Photos.

Визуализатор не записывает системный звук. Он использует доступный сигнал состояния приложения и визуальную генерацию, поэтому разрешение на запись экрана и аудио не требуется.

## Поведение при отказе

- Основная панель продолжает работать.
- Недоступная capability скрывается или команда возвращает отказ.
- Приложение не должно повторно открывать системный prompt при каждом polling tick.
- Пользователь может отключить необязательный monitor в настройках.

## Правило для будущего SDK

Расширение должно заранее объявлять capabilities в manifest. Host показывает пользователю причину доступа до системного prompt и не запускает адаптер, пока capability не разрешена.

Расширение не получает системное разрешение автоматически только потому, что оно установлено. Неиспользуемые capabilities не должны активироваться.
